# Thesis Tracker

## Overview

Track whether the core investment case is strengthening, weakening, or breaking. This skill helps turn scattered updates into a disciplined record of what the thesis was, what evidence matters, and what would falsify it.

## Workflow

1. Define the thesis.
   Capture direction, the one-line thesis, supporting pillars, risks, valuation view, and explicit break conditions.
2. Log new evidence.
   Record what happened, when it happened, and which thesis pillar it affects.
3. Score the thesis.
   Mark each pillar as strengthening, neutral, or weakening.
4. Update conviction.
   State whether the new evidence changes sizing, urgency, or target value.
5. Review upcoming proof points.
   Keep the next catalysts tied to the thesis, not as a separate generic calendar.

## Minimum Deliverable

- One-line thesis
- 3 to 5 supporting pillars
- 3 to 5 falsifiers or risks
- Update log with dates
- Current conviction and action bias

## Core Principle

Track disconfirming evidence as seriously as confirming evidence. A thesis is only useful if it can be proven wrong.

## Red Flags

- Thesis statements so vague that any result can be explained away
- Only logging positive evidence
- Letting valuation drift without revisiting the original case
- Confusing stock performance with thesis validation

## Handoff

Use `model-update` when thesis changes require new numbers, and `catalyst-calendar` when the next proof points need a dedicated event view.
