# Catalyst Calendar

## Overview

Build a forward-looking event map so the user can prioritize attention and position around upcoming catalysts. The goal is not to list every event, but to highlight the events most likely to move names in the universe.

## Workflow

1. Define the universe.
   Confirm the companies, sector scope, time horizon, and whether macro events belong in the same view.
2. Gather catalysts.
   Include earnings dates, investor days, conferences, regulatory decisions, product launches, M&A milestones, and major macro releases where relevant.
3. Rank the impact.
   Label each event by likely importance and note whether it is likely to affect a specific name, the group, or the market.
4. Add positioning context.
   Capture whether the setup looks supportive, risky, or neutral into the event.
5. Publish the calendar.
   Present a sortable table and a short weekly or monthly preview.

## Minimum Deliverable

- Date
- Event
- Company or sector
- Catalyst type
- Impact level
- Brief positioning note

## Good Questions

- Which events are likely to move estimates or sentiment?
- Which events are binary enough to change positioning?
- Which recurring events deserve regular monitoring?

## Red Flags

- Treating unverified earnings dates as final
- Mixing routine housekeeping items with true stock-moving catalysts
- Ignoring second-order events like conferences or regulatory deadlines

## Handoff

Use `earnings-preview` ahead of key reporting events and `morning-note` for near-term weekly summaries.
