# Earnings Preview

## Overview

Build a pre-earnings setup that tells the user what matters, where expectations sit, and how the stock could react across scenarios.

## Workflow

1. Set the event context.
   Confirm the company, quarter, report date, and whether it reports pre-market or after the close.
2. Gather expectations.
   Capture consensus for revenue, EPS, guidance, and the few KPIs that matter most for this name.
3. Define the setup.
   Note recent stock performance, sentiment, implied move, and whether the bar feels high or low.
4. Build scenarios.
   Write bull, base, and bear cases with the operational conditions that would trigger each one.
5. Rank the watch items.
   Identify the 3 to 5 data points or commentary topics most likely to move the stock.

## Minimum Deliverable

- Event timing
- Consensus snapshot
- Bull, base, and bear scenario table
- Ranked list of key metrics to watch
- Brief read on positioning and likely stock sensitivity

## Good Preview Questions

- What is the market actually debating into the print?
- Which KPI matters more than headline revenue or EPS?
- What level of guide is already priced in?
- Would a small beat still be enough if sentiment is stretched?

## Red Flags

- Treating published consensus as the only bar when whispers differ
- Ignoring stock setup and options-implied expectations
- Overweighting stale guidance without checking recent demand signals

## Handoff

When the company reports, move from this skill to `earnings-analysis`.
